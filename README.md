## Course

## Project

## Programming Language

## Description
The Municipal Financial Management System (MFMS) is a
menu-driven C application designed to provide basic
municipal financial management functionality.

## System Modules

- Employee Management
- Budget Management
- Supplier Management
- Asset Management
- Reports
